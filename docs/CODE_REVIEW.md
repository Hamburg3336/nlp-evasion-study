# 代码审核与发布调整

审核日期：2026年11月20日。修改仅落在独立仓库副本；原实验数据、训练检查点、正式预测、报告和历史源码快照保留。

## 已处理问题

| 问题 | 调整与验证 |
|---|---|
| 只有补充脚本，依赖相邻未上传目录 | 纳入原任务全部src及运行器；目录统一为仓库内experiment |
| 部分分析从历史核验脚本导入指标，额外依赖本地报告路径配置 | 提取独立analysis_utils，保留原指标公式；发布结果由独立标准库实现复算 |
| 导入全局配置会创建运行目录，dry-run并非完全不写 | 配置改为显式ensure_directories；原任务运行器在非dry-run时初始化 |
| 首次加载原始数据时父目录可能不存在 | load_raw显式建立原始数据目录 |
| 模型下载只为检查32字节却读取整个权重 | 改为流式只读32字节 |
| 代码强制默认镜像站、本机网络经验写成通用前提 | 默认官方入口，HF_ENDPOINT可配置；下载说明改为可选兼容路径 |
| 直接指标函数未明确拒绝空输入、长度不一致或未知标签 | 加入输入校验，正常指标计算不变 |
| 缺少重训后的输入清单生成入口 | 增加record_inputs.py，记录实际来源并可严格核对原快照 |
| GitHub结果不可在无模型条件下核查 | 发布34组预测与指标；独立复算Accuracy、Macro-F1、类别指标、混淆矩阵和概率约束 |
| 只给区间表，缺少轻量复算入口 | 发布匿名回答组编号与2×2预测，复算191组／5000次的五项配对区间 |
| 公开目录混杂完整数据、巨型权重、缓存和个人封面 | 采用明确文件清单导出，忽略运行产物；数据和模型提供获取入口与原哈希 |
| 历史一次性修订工具可能覆盖新报告 | 不纳入上传目录；仓库聚焦实验、分析及结果复核 |

原训练代码的格式和导入也已统一；不将代码审查解释为重新训练验证。模型训练、数据划分、损失权重、开发选轮次与九类映射规则保留原设计。

- QEvasion的title划分降低部分泄漏风险，不能证明独立访谈来源划分。
- QNLI的共享句子和有限测试来源信息已披露，当前结果不能替代来源级独立评测。
- 九类测试金标缺失，细类错误分解基于开发集；不是独立九类测试。
- 原QNLI神经头和整体微调控制仅seed42，新增三源种子只覆盖固定表示协议。
- 回答组bootstrap条件于已有检查点；五项区间均跨0，不构成稳定提升证据。
- 歧义记录排除同时改变数据、步数、顺序和权重，不是单因素标签噪声因果实验。
